The measurements

measured comes from canvas.measureText() on this exact string. computed is arithmetic on those values and the CSS. No third category exists on this page, which is the point.

What letter-spacing does to a shirorekha

Devanagari hangs from a connecting headline. letter-spacing inserts space after every cluster, so a global tracking token cuts that line into pieces. Scope tracking with :lang(); never apply a global negative track to Indic text.

Where JavaScript miscounts

ि is stored after its consonant and drawn before it, so slicing by index cuts a cluster in half. Counts here come from Intl.Segmenter running now, not from an expected value — engines disagree, and the disagreement is the finding.

What this build does not do

The fallback detector is missing on purpose. Its width-comparison method reported “substituted” for Noto Sans Devanagari — a face that certainly renders क — because both generic families resolve to the same physical face here, leaving the two baselines with nothing to compare. A confidently wrong badge is worse than an absent module. document.fonts.check() is no help either: it returns true for a font name invented on the spot.
